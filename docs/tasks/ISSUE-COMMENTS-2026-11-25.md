## #109 (Home counts show 0 after playback)

The counts on the home tiles now keep their last value while the list is reloaded. This is in the current version (1.4.9). Please update and tell us if you still see 0 after playback.

## #112 (Playlist disappears by itself)

Thank you, and thanks to the second reporter for the hint that it only happens on the Fire TV. Two changes so far:

- Since 1.4.4 a saved playlist list that cannot be read is no longer overwritten by the next save.
- The next version no longer creates a new secure key when the old one cannot be read for a moment (seen on some boxes after a restart). My assumption is that this made the saved login unreadable for good. This is a hypothesis; I cannot see the device. If the app still cannot read the saved list, it now says so on the empty home screen and asks you to add the playlist again.

Please try the next version and tell us if a playlist still disappears, and whether the box had been restarted before.

## #130 (Turn off score notification)

You can turn the alerts off in Settings > Sports Hub ("Alerts for games of your teams"). "Delay" holds an alert back; the next version offers up to 120 seconds (before: 60). Turning alerts off for single teams or games is not possible yet.

## #96 (Genre categories before the provider's categories)

The next version has a switch in Settings > Live TV: "Genre categories in Live TV". Off = only your provider's categories, in its order, right after "All channels". It is on by default. For Movies and Series the switch "Automatic genres" (Settings > Genres & categories) already exists; it is off by default.

## #125 (Films start view, "Recently added" row)

The row "Recently added" on the Movies and Series start view now takes the newest titles by the provider's added date, like the "Recently added" page. Before it took the last entries of the playlist, which differs when the provider does not list titles by date. This will be in the next version. Please check that both show the same first titles.

## #151 (Combine series and their seasons)

The next version has an option for this: Settings > Playlists > Series > "Combine seasons" (off by default). For Xtream providers that list every season as its own series ("Show S01", "Show S02"), the seasons then appear as one series.

Note: the history and "My list" entries of those series start again while the option is on (the series id changes). The old ones come back when you switch the option off.

To be sure this fits your provider: which kind of playlist do you use (Xtream login, M3U link, Stalker portal), and how is a season named in the list (for example "Show S02" or "Show - Staffel 2")? A short example name is enough, please without address or login.

## #146 (Tunneling playback)

The next version has an option: Settings > Player > Source & quality > "Tunneled playback (Live TV)" (off by default). It only takes effect if your device can do it for the channel. If the picture stays black or the sound is out of sync, switch it off. I could not measure whether it helps against the stutter; please try it on a channel that shows the problem and tell us the result and your device.

## #10 (Seeking in MKV files without Cues)
