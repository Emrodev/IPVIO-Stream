## 4. Risks and open points (check these first)
- **Media3 APIs not checked against the library:** `DownloadManager`, `DownloadRequest.Builder` (`setMimeType`, `setData`), `DownloadService.sendAddDownload/sendRemoveDownload/sendSetStopReason`, `DownloadNotificationHelper.buildProgressNotification`, `Requirements`, `Cache.getCachedLength`, `CacheDataSource` read-only setup, `MimeTypes.APPLICATION_M3U8/APPLICATION_MPD`, `DownloadManager.Listener` callback signatures. Verify each one on the build.
- **Player core change:** `PlayerScreen.kt` data source wraps `DownloadStore.playbackFactory` (one line). Review with the maintainer.
- **HLS offline playback** (cache per segment, `isLocal` decision) is the riskiest part.
- **Retry** of a failed download removes it and re-adds after 500 ms (unverified).
- **Season download** shows one toast per refused episode.
- **Auto-delete:** "used" = day of last playback (written at most once per hour); never-played downloads count from the first check.
- **Sidebar Downloads entry** hides while the tab is open after the last download is removed (until next open).
- **Multi view with four streams:** provider connection limits and weak decoders may not hold. Numbers (bitrate, size, start step 400 ms) are starting values.
- **Phone programme search:** Xtream channels partly (max 40 per search, first search can be partial).
- **TV programme search:** Xtream short guide only from the cache filled by `Epg.now`, up to 40 channels per search, 9 s limit.
- **Person search:** needs the user's TMDB key. Matching of owned titles uses the existing `LibMatch` (title and year ±1).
- **Sport row:** the "league" shown is the channel group, not a real league.
- **Icons:** Downloads and the category tiles use existing icons; no magnifier icon exists.
- **Not done:** size estimate per quality (needs playlist duration); Wi-Fi-only default stays off (user's choice); PhoneImport option b (confirmation on TV before storing the VPN key); `docs/SETTINGS.md` and `docs/PHONE.md` not updated; CHANGELOG entries say "Not device tested yet" everywhere.
- **Sidebar order for existing users:** the Downloads entry is added automatically; users who hid it keep it hidden.
